🔍 Job Hunter

Guía de instalación

Búsqueda de empleos - Job hunter

Antes de empezar, tienes que tener instalado:

🐍
Python 3.12+python.org/downloads
🔀
Gitgit-scm.com
🪟
Windowsscripts .bat/.ps1 son de Windows
📬
Telegram (opcional)para notificaciones

Clona el repositorio

Esto crea la carpeta job-hunter/ con job_hunter/ adentro.

git clone https://github.com/ambrociocastanazag-ctrl/job-hunter.git
cd job-hunter/job_hunter

Crea el entorno virtual

Se crea como carpeta hermana de job_hunter/, así que la activación sube un nivel.

python -m venv ../venv
../venv/Scripts/activate
💡 En Linux/Mac el activador es source ../venv/bin/activate, pero el resto del proyecto (los scripts .bat/.ps1 de automatización) es específico de Windows.

Instala las dependencias

pip install -r requirements.txt

Configura las variables de entorno

Copia la plantilla y edítala. Este archivo solo guarda secretos y ajustes de máquina — nunca la configuración de búsqueda.

copy .env.example .env
TELEGRAM_BOT_TOKEN=tu_token_aqui
TELEGRAM_CHAT_ID=tu_chat_id_aqui
DATABASE_URL=sqlite:///data/jobs.db
LOG_LEVEL=INFO
📬 ¿Sin bot de Telegram todavía? Escríbele a @BotFather → /newbot → copia el token. Luego mándale cualquier mensaje a tu bot y visita https://api.telegram.org/bot<TOKEN>/getUpdates para obtener tu chat_id. También puedes dejarlo vacío por ahora y configurarlo después desde el dashboard (Avanzado → Notificaciones).

Inicia el dashboard

python dashboard/app.py

Deberías ver:

Dashboard en http://127.0.0.1:5000
 * Running on http://127.0.0.1:5000

Abre esa URL en tu navegador — ya está escuchando en local.

Configura qué buscar

Todo se ajusta desde la web, sin tocar código:

  • Configuración — modalidad, sitios, keywords, ubicaciones, habilidades, umbral de score
  • Avanzado — regex de filtros, pesos de scoring, detección de stack, parámetros de ejecución

Lanza la primera corrida

La primera corrida trae vacantes de los últimos 30 días. Desde Historial, elige modo inicial y pulsa Ejecutar ahora — verás el log en vivo.

O por línea de comandos, en otra terminal con el entorno activado:

python main.py --mode initial

(Opcional) Automatiza las corridas

Desde Horarios puedes crear corridas recurrentes (qué días, qué hora) y, si quieres que el dashboard se abra solo al iniciar sesión en Windows, instalar la tarea de arranque con un botón — sin tocar el Programador de tareas a mano.
